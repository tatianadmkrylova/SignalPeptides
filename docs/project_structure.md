# Project structure

This document describes the organization of the repository, the purpose of the main directories and files, and the origin of the datasets used in the project.

## `data/`

The `data/` directory contains the datasets used in the project. Files are organized according to their origin and processing stage.

The main subdirectories are:

```text
data/
├── raw/
├── external/
├── interim/
└── processed/
```

### `data/raw/`

This directory contains datasets obtained directly from external databases before additional processing.

```text
data/raw/
├── uniprot/
└── signalpeptide_de/
```

### `data/raw/uniprot/`

This directory contains the original UniProt datasets used in the project.

The datasets used for the analyses correspond to versions downloaded before the UniProt update of 18 July 2026.

- `uniprot_bacteria_signal_confirmed_exp_before_update.csv` — bacterial proteins with experimentally supported signal peptide annotations in UniProt.
- `uniprot_mammalia_signal_confirmed_exp_before_update.csv` — mammalian proteins with experimentally supported signal peptide annotations in UniProt.
- `uniprotkb_taxonomy_viruses_AND_ft_sign_entry.csv` — viral proteins with signal peptide annotations in UniProt. This is the pre-update dataset used in the analyses.
- `uniprotkb_viruses_without_signalpeptide_newrequest.csv` — viral proteins without annotated signal peptides, used to construct the negative dataset.

### `data/raw/signalpeptide_de/`

This directory contains the original datasets obtained from signalpeptide.de.

- `signalpeptide_bacteria.csv` — bacterial protein records obtained from signalpeptide.de.
- `signalpeptide_mammalia.csv` — mammalian protein records obtained from signalpeptide.de.
- `signalpeptide_viruses.csv` — viral protein records obtained from signalpeptide.de, including protein identifiers and signal peptide information.

## `data/external/`

This directory contains datasets obtained from external resources that are used as reference datasets rather than generated by the project scripts.

### `data/external/signalp_training_set/`

- `protein_ids_dataset_signalP_training_set.txt` — protein identifiers from the SignalP training set.

## `data/interim/`

This directory is used for intermediate files generated during data preparation.

### `data/interim/fasta/`

This directory contains FASTA files generated for SignalP 6.0 analyses.

The FASTA files are generated from the source datasets and are not tracked by Git because they can be regenerated using the provided scripts.

A `.gitkeep` file is used to preserve the directory in the repository.

## `data/processed/`

This directory contains metadata and processed datasets generated from the raw or external data.

```text
data/processed/
├── uniprot/
├── signalpeptide_de/
└── signalp_training_set/
```

### `data/processed/uniprot/`

This directory contains UniProt metadata generated for the UniProt-derived datasets.

- `no_signalp_nodublons_viruses_entries_metadata.csv` — UniProt metadata for the viral negative dataset after duplicate removal.
- `uniprot_bacteria_signal_confirmed_exp_before_update_metadata.csv` — metadata corresponding to the pre-update bacterial UniProt dataset.
- `uniprot_mammalia_signal_confirmed_exp_before_update_metadata.csv` — metadata corresponding to the pre-update mammalian UniProt dataset.
- `uniprotkb_taxonomy_viruses_AND_ft_sign_before_update_metadata.csv` — metadata corresponding to the pre-update viral UniProt signal peptide dataset.
- `uniprotkb_viruses_without_signalpeptide_newrequest_metadata.csv` — metadata corresponding to the viral dataset without annotated signal peptides.

### `data/processed/signalpeptide_de/`

This directory contains processed signalpeptide.de datasets and UniProt metadata retrieved for proteins present in these datasets.

- `signalpeptide_bacteria_confirmed.csv` — bacterial proteins from signalpeptide.de retained for the analysis.
- `signalpeptide_bacteria_uniprot_meta.csv` — UniProt metadata for bacterial proteins from signalpeptide.de.
- `signalpeptide_mammalia_confirmed.csv` — mammalian proteins from signalpeptide.de retained for the analysis.
- `signalpeptide_mammalia_uniprot_meta.csv` — UniProt metadata for mammalian proteins from signalpeptide.de.
- `signalpeptide_viruses_all_metadata.csv` — UniProt metadata for viral proteins used from signalpeptide.de.

### `data/processed/signalp_training_set/`

This directory contains UniProt metadata retrieved for proteins from the SignalP training set.

- `protein_ids_dataset_signalP_training_set_metadata.csv` — UniProt metadata corresponding to the SignalP training set protein identifiers.

## `scripts/`

The `scripts/` directory contains the scripts used for dataset acquisition, metadata retrieval, FASTA preparation, and statistical analysis.

```text
scripts/
├── 01_data_acquisition/
├── 02_metadata/
├── 03_prepare_signalp/
└── 04_analysis/
```

## `scripts/01_data_acquisition/`

This directory contains scripts used to retrieve the initial datasets.

- `uniprot_dataset.sh` — retrieves protein datasets from UniProt according to the queries defined in the script.
- `nosignalpeptide_data.sh` — retrieves viral proteins without annotated signal peptides from UniProt for construction of the negative dataset.
- `signalpeptide.py` — retrieves protein records from signalpeptide.de for selected taxonomic groups.

## `scripts/02_metadata/`

This directory contains scripts used to retrieve additional protein metadata from UniProt.

- `uniprot_request_metadata.py` — retrieves UniProt metadata for proteins from UniProt-derived datasets.
- `uniprot_request_metadata_signalpeptide.py` — retrieves UniProt metadata for proteins obtained from signalpeptide.de.

## `scripts/03_prepare_signalp/`

This directory contains scripts used to prepare protein sequences for SignalP 6.0.

- `seq_full_prot_fasta_sec_acc.py` — retrieves full protein sequences in FASTA format using protein accession numbers.
- `fasta_for_signalp.sh` — prepares FASTA files for SignalP analysis and removes duplicate protein sequences.

## `scripts/04_analysis/`

This directory contains the R scripts used for statistical analyses and visualization.

### `Datasets.R`

Compares the datasets obtained from UniProt, signalpeptide.de, and the SignalP training set.

The script performs analyses including:

- comparison of UniProt and signalpeptide.de datasets;
- calculation of dataset intersections;
- generation of Venn diagrams;
- analysis of signal peptide length distributions;
- comparison of signal peptide lengths between UniProt and signalpeptide.de;
- analysis of UniProt ECO evidence codes;
- comparison of UniProt and signalpeptide.de datasets with the SignalP training set;
- comparison of signal peptide length distributions between viral, bacterial, and mammalian UniProt proteins.

Generated figures are saved in `results/figures/`.

### `SignalP_UniProt_signalpeptide_analysis.R`

Compares SignalP 6.0 predictions with signal peptide annotations from UniProt and signalpeptide.de for viruses, bacteria, and mammals.

The script includes:

- comparison of SignalP and UniProt signal peptide lengths;
- comparison of SignalP and signalpeptide.de signal peptide lengths;
- comparison between UniProt and signalpeptide.de annotations;
- evaluation of SignalP predictions for the viral dataset;
- analysis using a viral negative dataset;
- calculation of precision, recall, specificity, accuracy, F1 score, MCC, and balanced accuracy;
- generation of a confusion matrix.

### `SignalP_virus_UniProt_prediction_analysis.R`

Performs a detailed analysis of SignalP 6.0 predictions for viral proteins with signal peptides annotated in UniProt.

The script includes:

- analysis of viral proteins classified as `OTHER` by SignalP 6.0;
- analysis of SignalP prediction probabilities;
- comparison of signal peptide lengths between proteins predicted and not predicted to contain a signal peptide;
- identification of high-confidence SignalP predictions.

Detailed instructions for running the scripts are provided in `docs/run_scripts.md`.


## `results/signalp/`

This directory contains SignalP 6.0 prediction results organized according to organism group and source dataset.

```text
results/signalp/
├── bacteria_signalpeptide_de/
├── bacteria_uniprot/
├── mammalia_signalpeptide_de/
├── mammalia_uniprot/
├── negative_dataset/
├── viruses_signalpeptide_de/
└── viruses_uniprot/
```

### `results/signalp/bacteria_signalpeptide_de/`

- `output_bacteria_confirmed.gff3` — SignalP predictions in GFF3 format.
- `prediction_results_bacteria_confirmed.txt` — SignalP prediction results in text format.

### `results/signalp/bacteria_uniprot/`

- `output_signalp_bacteria_uniprot.gff3` — SignalP predictions in GFF3 format.
- `prediction_results_bacteria_uniprot.txt` — SignalP prediction results in text format.

### `results/signalp/mammalia_signalpeptide_de/`

- `output_mammalia_confirmed.gff3` — SignalP predictions in GFF3 format.
- `prediction_results_mammalia_confirmed.txt` — SignalP prediction results in text format.

- `output_signalp_mammalia_uniprot.gff3` — SignalP predictions in GFF3 format.
- `prediction_results_mammalia_uniprot.txt` — SignalP prediction results in text format.

## `results/figures/`

This directory contains figures generated by the R analysis scripts.

The figures include:

- UniProt and signalpeptide.de dataset intersections;
- Venn diagrams;
- signal peptide length distributions;
- comparisons of signal peptide lengths between databases;
- comparisons between viral, bacterial, and mammalian proteins;
- UniProt ECO evidence distributions;
- comparisons with the SignalP training set;
- SignalP prediction summaries;
- SignalP probability analyses;
- SignalP confusion matrix and performance analyses.

Examples include:

- `uniprot_all_group_sp_length.png` — comparison of UniProt signal peptide length distributions between bacteria, mammals, and viruses.
- `distribution_length_boxplot_viruses_intersection.png`
- `distribution_length_boxplot_bacteria_intersection.png`
- `distribution_length_boxplot_mammalia_intersection.png`
- `counts_eco_uni_virus.png`
- `counts_eco_uni_bacteria.png`
- `counts_eco_uni_mammalia.png`
- `conf_matrix_vir.png`
- `359_n0_predictions_signalp6.png`
- `yes_no_predictions_signalp6_virus_uniprot.png`

All figures in this directory can be regenerated using the R scripts in `scripts/04_analysis/`.

## Data version note

The analyses in this repository are based on the UniProt datasets downloaded before the UniProt update of 18 July 2026.

These versions are intentionally preserved so that the stored datasets, SignalP outputs, statistical analyses, and generated figures correspond to the same data versions used during the project.
